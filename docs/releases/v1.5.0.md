## 自动中英文界面 / Automatic Chinese & English UI

- 游戏为简体中文（`zh-CN`）时，DPS 面板与 F9 设置显示中文；其他所有语言，包括繁体中文，统一显示英语。
- 游戏内切换语言后立即更新，无需重启，不会清空伤害统计或重置计时；玩家名字保持原样。
- GitHub README 与安装包说明均提供中文、English 切换入口。
- 保留多人分房统计、房间结算、双计时、面板缩放与位置锁定功能。

85 项语言测试与 29 项房间规则回归测试通过，已完成游戏内测试（2026-08-27）。

### English

- The DPS overlay and F9 settings use Chinese only when the game is set to Simplified Chinese (`zh-CN`). All other languages, including Traditional Chinese, use English.
- Language changes apply immediately without restarting, clearing damage statistics or resetting timers. Player names remain unchanged.
- Both the repository and plugin package include Chinese and English READMEs with language navigation.
- Multiplayer room isolation, room results, dual timers, scaling and position locking remain available.

Passed 85 localization checks, 29 room-rule regression checks, and in-game testing on 2026-08-27.

## 下载与安装 / Download & installation

需要 Windows 版 Sephiria（Steam AppID **2436940**）与 **BepInEx 5 / Unity Mono**。不适用于 BepInEx 6 或 IL2CPP。

1. 退出游戏。
2. 下载 `SephiriaDpsMeter-v1.5.0.zip`，将其中的 `BepInEx` 文件夹合并到游戏根目录；或下载独立 `SephiriaDpsMeter.dll` 放入 `BepInEx/plugins/`。
3. 更新时覆盖同名 DLL、保留配置，不要同时保留多个版本。
4. 启动游戏，按 F9 打开设置。

Requires Windows Sephiria and **BepInEx 5 / Unity Mono**, not BepInEx 6 or IL2CPP. Exit the game, merge the ZIP's `BepInEx` folder into the game directory, or place the standalone DLL in `BepInEx/plugins/`. Replace the old DLL, keep your configuration, and do not install multiple versions. Start the game and press F9 for settings.

安装包不包含加载器、游戏程序集或其他模组。`Source code` 为源码包，不能直接作为插件安装；`SHA256SUMS.txt` 提供 ZIP 与 DLL 校验值。

The package does not bundle the loader, game assemblies or other mods. `Source code` archives are not installable plugin packages. SHA-256 checksums for the ZIP and DLL are provided in `SHA256SUMS.txt`.
