# Sephiria DPS Meter v1.4.2

《赛菲莉娅》多人 DPS 面板 · by G-Yoka

- Steam AppID：**2436940**
- 当前游戏版本已由作者实机验证（2026-08-27）。
- 需要 **BepInEx 5 / Unity Mono / Windows**，不适用于 BepInEx 6 或 IL2CPP。

## 下载与安装

推荐下载下方 Assets 中的 **SephiriaDpsMeter-v1.4.2.zip**。

1. 退出游戏。
2. Steam 库右键游戏 → 管理 → 浏览本地文件。
3. 将 ZIP 中的 `BepInEx` 文件夹合并到游戏根目录。
4. 启动游戏，按 **F9** 打开设置。

只想更新插件，也可下载 **SephiriaDpsMeter.dll**，放入 `BepInEx/plugins/`。

**本包不包含 BepInEx 加载器**；未安装者请先安装 BepInEx 5。不要下载 `Source code` 作为安装包，不要同时保留多个版本的 DLL。原配置可保留。

## 功能

- 按战斗房间统计玩家伤害、伤害占比、DPS 和命中反馈计数。
- 房间结束冻结结果，不使用空闲超时重置；同时显示房间用时和本局用时。
- 读取游戏原生多人伤害反馈，不额外发送模组网络消息。
- 主面板支持拖动、位置锁定、25%–100% 不透明度和 60%–120% 缩放。
- F9 设置菜单背景不透明度固定为 75%；打开时使用系统光标。

本次发布包含此前已完成的输入卡键修复、白圈背景修复、列对齐与缩放调整。

## 统计与兼容性提示

- 数据取决于本机收到的原生伤害反馈，非服务器全局战斗日志；多人分房时各客户端数据可能不同。
- 命中是每批反馈按玩家去重后的计数，不是逐弹体计数或命中率。
- `SephiriaModSettings` 是可选的独立模组，不包含在本包内。
- 设置窗口不暂停游戏，请在安全区域调整。
