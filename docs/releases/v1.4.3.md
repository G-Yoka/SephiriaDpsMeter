## 多人分房统计修复

- 修复两名玩家分别在不同房间战斗时，伤害与 DPS 被合并显示的问题。
- 仅统计本地玩家当前房间：所属玩家必须同层，且玩家与受击目标都在当前战斗区域内。
- 换房或换层时重新开始统计，不依赖战斗状态必须先退出再进入。
- 房间区域无法识别时暂停计入伤害并显示提示，不会退回全局统计。

分房统计修复已实机测试通过（2026-08-27）；29 项房间匹配规则测试通过。原有 F9 设置、缩放、位置锁定与双计时保持不变。

## 下载与安装

需要 Windows 版 Sephiria（Steam AppID **2436940**）及 **BepInEx 5 / Unity Mono**，不是 BepInEx 6 或 IL2CPP 插件。

1. 退出游戏。
2. 下载 `SephiriaDpsMeter-v1.4.3.zip`，将其中的 `BepInEx` 文件夹合并到游戏根目录；或只下载 `SephiriaDpsMeter.dll`，放入 `BepInEx/plugins/`。
3. 更新时覆盖同名 DLL 并保留配置，不要同时保留多个版本。
4. 启动游戏，按 F9 打开设置；进入可识别的战斗房间后自动统计。

安装包不包含加载器、游戏程序集或其他模组。`Source code` 是源码包，不是可直接安装的插件；`SHA256SUMS.txt` 提供 ZIP 与 DLL 的 SHA-256 校验值。

不同房间或楼层的队友不会显示在当前房间统计中。缺少原生战斗区域的特殊战斗可能无法统计；客户端网络同步范围仍可能影响数据完整性。

完整功能与统计口径见 [README](https://github.com/G-Yoka/SephiriaDpsMeter/blob/v1.4.3/README.md)。
