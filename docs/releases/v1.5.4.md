## 死亡、复活与大厅生命周期 / Death, respawn and lobby lifecycle

- 本地玩家死亡时冻结当前 DPS 结果；在同一房间复活后保留双方玩家数据并继续累计。
- 整局失败时在死亡结算阶段保留最终结果，返回联机大厅后清空伤害、DPS、命中、房间编号与计时。
- 只有地下城整局正在运行时才识别房间；攻击联机大厅训练假人不会启动统计或停留在“房间识别中”。
- 48 项房间生命周期测试与 112 项语言测试通过，并于 2026-08-30 完成双人联机游戏验证。

### English

- Freezes the current DPS result when the local player dies and continues the same totals after a same-room respawn.
- Keeps final results on the failed-run death screen, then clears damage, DPS, hits, room number and timers after returning to the multiplayer lobby.
- Room detection only runs during an active dungeon run. Attacking a lobby training dummy does not start recording or leave the panel stuck on “Locating room.”
- Passed 48 room-lifecycle checks, 112 localization checks and two-player multiplayer testing on 2026-08-30.

## 安装 / Installation

需要 Windows 版 Sephiria 与 **BepInEx 5 / Unity Mono**。退出游戏，将 `SephiriaDpsMeter-v1.5.4.zip` 中的 `BepInEx` 文件夹合并到游戏根目录；也可将独立 DLL 放入 `BepInEx/plugins/`。覆盖旧 DLL 并保留配置，不要同时保留多个版本。

Requires Windows Sephiria and **BepInEx 5 / Unity Mono**. Exit the game, merge the ZIP's `BepInEx` folder into the game directory, or place the standalone DLL in `BepInEx/plugins/`. Replace the old DLL, keep your configuration and do not install multiple versions.

ZIP 内含中英文说明和界面截图，不包含 BepInEx、游戏程序集或其他模组。`Source code` 是源码包，不是插件安装包；`SHA256SUMS.txt` 提供 ZIP 与 DLL 的 SHA-256 校验值。

The ZIP includes bilingual documentation and UI screenshots. It does not include BepInEx, game assemblies or other mods. `Source code` archives are not installable plugin packages. `SHA256SUMS.txt` contains the ZIP and DLL checksums.
