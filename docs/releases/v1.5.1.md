## 繁体中文语言映射 / Traditional Chinese language mapping

- 游戏选择简体中文（`zh-CN`）或繁体中文（`zh-TW`）时，DPS 面板与 F9 设置均显示简体中文。
- 其他语言继续显示英语；切换语言不会清空伤害统计或重置计时。
- 112 项本地语言测试与 29 项房间规则回归测试通过，已完成游戏内验证（2026-08-28）。

### English

- Both Simplified Chinese (`zh-CN`) and Traditional Chinese (`zh-TW`) game settings now use the Simplified Chinese DPS overlay and F9 menu.
- All other languages continue to use English. Language switching does not clear damage statistics or reset timers.
- Passed 112 local localization checks, 29 room-rule regression checks and in-game testing on 2026-08-28.

## 安装 / Installation

需要 Windows 版 Sephiria 与 **BepInEx 5 / Unity Mono**。退出游戏，将 `SephiriaDpsMeter-v1.5.1.zip` 中的 `BepInEx` 文件夹合并到游戏根目录；也可将独立 DLL 放入 `BepInEx/plugins/`。覆盖旧 DLL 并保留配置，不要同时保留多个版本。

Requires Windows Sephiria and **BepInEx 5 / Unity Mono**. Exit the game, merge the ZIP's `BepInEx` folder into the game directory, or place the standalone DLL in `BepInEx/plugins/`. Replace the old DLL, keep your configuration and do not install multiple versions.

ZIP 内的双语说明位于 `docs/`。安装包不包含加载器、游戏程序集或其他模组。`Source code` 是源码包，不是插件安装包；`SHA256SUMS.txt` 提供 ZIP 与 DLL 的 SHA-256 校验值。

Bilingual instructions are included under `docs/`. The package does not include the loader, game assemblies or other mods. `Source code` archives are not installable plugin packages. `SHA256SUMS.txt` contains the ZIP and DLL checksums.
